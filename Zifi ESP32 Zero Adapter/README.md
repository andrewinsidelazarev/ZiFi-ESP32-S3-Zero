# ZiFi ESP32-S3-Zero → ESP-01 adapter

Переходник устанавливает модуль Waveshare ESP32-S3-Zero вместо ESP-01/ESP-01S.
ESP32-S3-Zero расположен сверху, а снизу платы выходит штекер 4×2 с шагом
2,54 мм и физической ориентацией ESP-01.

Подключены только четыре цепи:

| ESP-01, вид сверху | ESP32-S3-Zero |
|---|---|
| pin 1 `GND` | pad 17 `GND` |
| pin 4 `RX` | pad 2 `RX / GPIO44` |
| pin 5 `TX` | pad 1 `TX / GPIO43` |
| pin 8 `VCC` | pad 16 `3V3` |

`GPIO2`, `GPIO0`, `EN` и `RST` штекера ESP-01 намеренно не подключены.

## Важное ограничение питания

Переходник подаёт питание ESP-01 `3,3 В` прямо на контакт `3V3` модуля,
в обход его входа `5V` и штатного LDO. Подключать USB-C можно только после
извлечения переходника из основной платы: одновременное питание от USB и
контакта ESP-01 этим проектом не развязано.

Источник 3,3 В основной платы должен выдерживать пиковый ток Wi-Fi модуля.
До изготовления партии это необходимо проверить на реальной основной плате
под нагрузкой.

## Механика

- плата: `24 × 33 мм`, два слоя;
- ESP32-S3-Zero: два ряда по 9 комбинированных площадок; на B.Cu планарная
  медь `5,6 × 1,8 мм` смещена от отверстий наружу на `1,0 мм` зеркально
  (`−1,0 мм` слева, `+1,0 мм` справа), а на F.Cu сохранён размер
  `3,6 × 1,8 мм`;
- снизу: прямой мужской разъём `4×2`, шаг `2,54 мм`, корпусом на нижней стороне платы;
- ESP32 устанавливается сверху переходника, штырьки входят в 18 отверстий;
- USB-C ESP32 направлен к верхнему внешнему краю, антенна — к J1;
- плата прямоугольная, без верхнего выреза; под антенной нет меди;
- J1 припаивается с нижней стороны; длинные части штырей направляются вниз,
  в разъём основной платы.

Вид со стороны ESP32, модуль сверху:

```text
       ESP32-S3-Zero

       GND  NC  NC  RX    ← ближний к модулю ряд
       TX   NC  NC  3V3   ← нижний ряд
```

## Перегенерация

```powershell
python .\Tools\generate_adapter.py
```
