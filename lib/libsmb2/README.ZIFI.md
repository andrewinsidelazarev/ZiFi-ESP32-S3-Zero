# libsmb2 в прошивке ZiFi

Эта папка содержит неизменённые исходники открытой библиотеки `libsmb2` и
небольшой файл `library.json`, который объясняет PlatformIO, как их собирать.

- исходный проект: <https://github.com/sahlberg/libsmb2>
- зафиксированный commit: `aa5efdbcd5d48d48273691f17445221447a6ff74`
- версия из `configure.ac`: `6.1.0`
- лицензия библиотеки: LGPL-2.1-or-later

Файлы `COPYING` и `LICENCE-LGPL-2.1.txt` сохранены рядом с исходниками. Почти
весь код библиотеки оставлен без изменений: так его легче сравнить с оригиналом
и обновить. Пять небольших интеграционных правок помечены словом `ZiFi`:
остановка блокирующего серверного цикла из задачи FreeRTOS и передача сырого
тела `SET_INFO` серверному обработчику без включения глобального режима
passthrough, а также кодирование обычного `FILE_NAME_INFORMATION` тем же
проверенным способом, что и нормализованного имени. Ещё две правки разрешают
немедленно повторно занять TCP-порт после остановки и не разыменовывают нулевой
контекст при нехватке памяти. Русские учебные комментарии находятся прежде
всего в адаптере ZiFi, который связывает серверную часть библиотеки с UART/VFS.

## Почему библиотека хранится в репозитории

В Espressif Component Registry опубликована старая клиентская версия. Нужный
серверный API появился позже, поэтому сборка использует точный проверенный
commit, а не меняющийся архив из сети.

## Параметры сборки

`library.json` исключает только платформенные реализации Apple и Kerberos.
Для ESP32 выбирается уже имеющийся в upstream слой `include/esp`, а отсутствующая
в Arduino функция `gethostname()` реализована в адаптере ZiFi.

При распространении бинарной прошивки следует учитывать условия LGPL для
статически скомпонованной библиотеки и предоставлять получателю соответствующие
исходники/объектные файлы и текст лицензии. Это техническая памятка, а не
юридическая консультация.
